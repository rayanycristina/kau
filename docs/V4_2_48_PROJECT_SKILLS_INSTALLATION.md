# KAU Commercial OS — v4.2.48
## Project Skills Installation

Esta versão instala módulos internos de orientação para evolução contínua do SaaS KAU e da Sales Arena.

- `/skills/ui-ux-saas-architect.md`
- `/skills/product-systems-architect.md`

- `/skills/sales-arena-orchestrator.md`

## Objetivo
Criar uma camada interna de direção para que os próximos refinamentos do KAU sigam a mesma lógica de produto:

1. UI/UX SaaS Architect cuida do visual, hierarquia, responsividade, motion e aparência premium.
2. Product Systems Architect cuida de lógica, Supabase, métricas, cálculos, filtros e regras de negócio.
3. Commercial Performance Copy cuida de linguagem, status, CTAs, alertas e pressão operacional.
4. Sales Arena Orchestrator decide qual módulo consultar e como combinar os três.
