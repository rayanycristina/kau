# V4.2.62 — Finance Visual System Refinement

## Escopo
Refinamento exclusivamente visual da área de Vendas + Caixa Previsto + Histórico de movimentação.

## Preservado
- Supabase
- backend
- filtros
- cálculos
- regras de comissão, subcomissão, carteira, saque e caixa
- colunas e dados existentes
- Sales Arena

## Alterado
- tipografia unificada com prioridade para Geist/Inter/SF Pro Display
- spacing system baseado em 4px
- grid e alinhamento visual mais rigoroso
- elevation system mais silencioso e enterprise
- superfícies com depth layering, bordas suaves e luz indireta controlada
- tabela de movimentações com rows mais respiradas, hover premium e scrollbar minimalista
- tabela de vendas com visual mais financeiro, menos planilha e menos cyberpunk
- caixa previsto com lista mais limpa e ações menores
- saques registrados com aparência de extrato financeiro
- cards de resumo com acento lateral em vez de superfície saturada

## Direção visual
Clean luxury SaaS: Stripe, Linear, Vercel, Ramp, Mercury, Raycast e Notion Enterprise.
