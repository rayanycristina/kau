# KAU V4.2.7 — Sales Edit Workspace

Ajustes da área principal de Vendas:

- Adicionado botão de olho para abrir qualquer venda.
- Drawer de edição permite alterar cliente, telefone, cidade, vendedor, valor, comissão, quantidade, observação, data de recebimento, status e tipo de pagamento.
- Permite trocar PAD, COD e Pagamento Antecipado sem recriar venda.
- PATCH da API agora aceita atualização completa do registro de venda.
- Card Operação passa a representar comissões do dia: comissão do vendedor + carteira/ganho do operador quando a venda é de outro vendedor.
- Venda própria da Rayany continua sem adicional de 10% duplicado.
- Caixa continua mostrando apenas dinheiro confirmado/pago.
- Excluir e atualizar não disparam notificação de pedido gerado.
