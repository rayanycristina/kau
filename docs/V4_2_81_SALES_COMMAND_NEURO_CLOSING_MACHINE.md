# V4.2.81 — Sales Command Neuro Closing Machine

## Objetivo
Reconstruir o Sales Command como uma experiência guiada de fechamento, deixando de parecer CRM/kanban e passando a operar como uma máquina psicológica de condução comercial.

## Alterações principais
- Nova experiência visual do Sales Command em formato de cockpit de fechamento guiado.
- Radar de leads com leitura de momentum, estado emocional e risco.
- Motor de negociação com chance de fechamento, risco de perda e próximo movimento recomendado.
- Jornada guiada de fechamento com etapas psicológicas.
- Script dinâmico por tom: suave, consultivo, emocional, dominante, urgência e fechamento direto.
- IA de fechamento com leitura contextual da operação.
- Sistema de objeções com resposta, tom e estimativa de recuperação.
- Painel de momentum e sensor de fechamento.

## Preservado
- API de leads existente.
- Atualização de status via PATCH em /api/leads.
- Supabase como fonte de dados.
- Estrutura geral do KAU e demais módulos.
