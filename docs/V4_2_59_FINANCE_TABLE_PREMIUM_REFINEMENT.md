# V4.2.59 — Finance table premium refinement

## Objetivo
Refinar a tabela financeira / Histórico de movimentação para uma estética SaaS premium, silenciosa e enterprise.

## Ajustes visuais
- Substituição da aparência pesada/cyber por uma superfície dark premium inspirada em Linear, Stripe, Vercel e Superhuman.
- Tipografia refinada na tabela:
  - headers menores, uppercase e menos pesados
  - datas mais legíveis
  - registros com peso regular/medium
  - valores positivos e negativos com cores mais sofisticadas
- Redução drástica de glow e brilho visual.
- Separadores quase invisíveis usando baixa opacidade.
- Hover premium com transição curta de 180ms.
- Scrollbar minimalista para o painel financeiro.
- Status badges mais silenciosos e enterprise.
- Valores alinhados à direita com tabular nums para leitura financeira.

## Ajustes funcionais preservados
- Agrupamento por data continua recolhível.
- Cabeçalho do dia mostra total sacado quando houver saque.
- Entradas continuam usando data de liberação/pagamento do caixa.
- Coluna segue como Comissão, não Taxa.
- Saques continuam vinculando vendas quando o saque for registrado.
