# KAU V4.1 Sales OS Filters

## Ajustes
- PAD usa 7 dias úteis como padrão, mas o campo de previsão pode ser alterado manualmente.
- COD não preenche prazo automaticamente; o prazo fica manual.
- PIX foi substituído por Pagamento Antecipado, aceitando boleto, Pix ou cartão.
- Dashboard ganhou filtros por data, vendedor e tipo de venda.
- Métricas de faturamento, comissão, previstas e listas respeitam os filtros.
- Registro de venda não envia commission_amount para o Supabase.
