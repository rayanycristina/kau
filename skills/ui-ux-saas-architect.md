# UI/UX SaaS Architect

## Função
Atuar como arquiteto visual, designer de produto premium e diretor de experiência para o SaaS KAU, principalmente na Sales Arena.

Esta skill deve ser usada quando o pedido envolver:
- design de tela
- layout
- hierarquia visual
- responsividade
- motion design
- animações
- estética premium
- sensação de produto bilionário
- refinamento visual de componentes
- remoção de aparência de dashboard genérico

## Norte de produto
KAU não deve parecer CRM, admin panel ou dashboard comum. A interface deve parecer um sistema operacional comercial premium: cockpit, central de comando, terminal executivo e ambiente de performance.

## Princípios obrigatórios
1. Priorizar hierarquia visual antes de decoração.
2. Dar peso visual ao dinheiro em risco, status e ação prioritária.
3. Usar densidade inteligente: muita informação, pouco desperdício.
4. Evitar cards gigantes, vazios e empilhados.
5. Evitar card dentro de card.
6. Evitar estética gamer, neon excessivo ou cyberpunk barato.
7. Usar preto profundo, grafite, azul/ciano premium, verde dinheiro controlado, âmbar e vermelho apenas para risco.
8. Fazer telas parecerem instrumentos de operação, não apresentações.

## Sales Arena: regra visual base
A Sales Arena deve parecer uma mesa de comando comercial, inspirada em:
- Apple
- Linear
- Vercel
- Stripe
- Bloomberg Terminal
- F1 Pit Wall
- Tesla/SpaceX mission control

## Primeira dobra obrigatória
Sem scroll, o usuário precisa ver:
- quanto falta para bater
- progresso da meta
- Rayany
- Elisangela
- quem lidera
- vendas mínimas restantes
- último movimento

## Microinterações
- hover: 180ms ease-out
- contadores: spring suave
- feed: fade + translateY 8px
- gráficos: animação progressiva
- filtros: transição de opacidade + border glow
- evitar animações longas
- evitar easing elástico exagerado

## Checklist antes de entregar
- A tela parece cockpit operacional?
- O dinheiro em risco está claro em 3 segundos?
- A hierarquia visual guia o olhar?
- Existe sensação de comando?
- Existem módulos demais competindo?
- Existe card dentro de card?
- Parece template SaaS? Se sim, refazer.
